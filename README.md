Lab Project 3 — Dashboard de Vendas Xbox
Projeto de dashboard simples de vendas/assinaturas desenvolvido no Excel, a partir da base de dados fornecida no desafio da DIO.
Objetivo
Organizar e visualizar os dados de assinaturas para acompanhar o faturamento e identificar diferenças entre planos, tipos de assinatura e renovação automática.
Dados utilizados
A aba Base de dados contém 295 registros da base disponibilizada na atividade, com identificação do assinante, plano, renovação, tipo de assinatura, preços, adicionais, cupons e valor total.
Indicadores e visualizações
Na aba Dashboard, são apresentados:
- Faturamento total da base;
- Número de assinantes;
- Ticket médio (faturamento dividido pela quantidade de assinantes);
- Faturamento por plano (Core, Standard e Ultimate);
- Faturamento por renovação automática (Yes e No);
- Faturamento por periodicidade (Monthly, Quarterly e Annual);
- Gráficos de faturamento por plano e periodicidade.
Como reproduzir
1. Baixe o arquivo lab-project-2.xlsx.
2. Abra-o no Microsoft Excel ou no Google Planilhas.
3. Consulte a aba Base de dados para visualizar os registros.
4. Acesse a aba Dashboard para ver os indicadores e gráficos.
Os indicadores usam as funções SOMA, CONT.VALORES e SOMASE (armazenadas no arquivo com os nomes internacionais SUM, COUNTA e SUMIF). O ticket médio é calculado dividindo o faturamento pelo número de assinantes.
